# bellbored

A notification bell for bulletinbored. Shows an unread-count badge and a dropdown
panel of recent notifications for the current user. Notifications are stored in a
`notifications` table created automatically on first load.

## Features

- Unread-count badge in the navigation bar
- Dropdown list of recent notifications
- Mark-as-read on click (single or all)
- Creates its own database table on install
